# F1 2025 CLI

CLI tool for exploring F1 2025 season driver statistics.

## Features
- Show all drivers
- Filter by team
- Filter by country
- Drivers born after 2000
- Top N drivers by career points

## Data Source
Data from [formula1-datasets](https://github.com/toUpperCase78/formula1-datasets)

## Usage
```bash
python3 f1.py
```
